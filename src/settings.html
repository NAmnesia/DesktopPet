桌宠设置

模型服务

云端 API 与本地模型（Ollama 等）任意切换，全部走 OpenAI 兼容接口。

宠物人设

选择预设会填充下方提示词，选完还可以手动微调，保存后即生效。

番茄钟

在宠物右键菜单或托盘菜单点"开始番茄钟"。每段专注/休息结束时宠物会用 AI 现场生成一句不重样的提醒，同时弹系统通知。

一轮 = 专注 + 休息；跑完全部轮次后提醒"周期完成"并停止。进行中修改参数将在下次开始时生效。

屏幕观察（仅本地模型）

开启后宠物会定期"看一眼"你的屏幕（截屏发送给 本地 视觉模型，如 qwen2.5vl），然后用人设口吻主动搭话。截图只在内存中处理、不保存；使用云端 API 时此功能自动停用。

开启后约 25 秒会先看第一眼，之后按间隔执行；点评会避开最近说过的说法。需要模型支持视觉（qwen2.5vl 系列）。
