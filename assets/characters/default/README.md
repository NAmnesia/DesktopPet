# 角色文件夹说明（换肤）

把一个角色的图片放在以角色名命名的文件夹里，例如：

```
characters/
└── my-pet/
    ├── idle.png   # 待机（必需！没有它不会启用该角色）
    ├── talk.png   # 说话时（可选，缺省用 idle）
    └── drag.png   # 被拖拽时（可选，缺省用 idle）
```

- 支持格式：`.png` / `.jpg` / `.jpeg` / `.webp` / `.gif`（推荐透明背景 PNG）
- 建议尺寸：正方形（如 512×512），程序会按设置里的"宠物大小"自动缩放
- 放好图片后，打开 桌宠右键菜单 → 设置 → 外观，在"角色"下拉里就能看到新角色
- 建议图片主体居中、底部留少量空隙，效果最好

## 角色文件夹在哪里？

用户自定义角色放这里（设置界面有"打开角色文件夹"按钮）：

- Windows: `%APPDATA%/desktop-pet/characters/`
- 也可以直接放在程序目录的 `assets/characters/` 下（升级程序时会被覆盖，不推荐）

## 美术还没画好？

不放任何图片即可——程序会使用内置的 SVG 简易角色（一只奶油色的圆滚滚小生物），
等美术资源就绪后再放进文件夹就能自动替换，无需改任何代码。
